## What is MCD?

MCD is a platform that replaces CRO (Contract Research Organization) methods for pharmaceutical laboratories. Labs traditionally pay CROs to collect patient data through slow and expensive fieldwork. We replace that with a direct data pipeline.

Doctors load patients prescribed a drug into a dashboard. A WhatsApp bot powered by AI contacts each patient and conducts a smart questionnaire about drug consumption, processing text, audio, and images. A processing LLM aggregates all data sources and delivers structured intelligence to the lab. Non-responsive patients are flagged in red so the lab can distinguish adherent from non-responsive cases.
